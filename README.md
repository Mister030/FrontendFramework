# Frontend Framework: eerste React-project

Mijn eerste React-project, gemaakt bij het vak Frontend Framework (MBO Utrecht). Een kleine startpagina om React met Vite en Bootstrap op te zetten.

## Starten

```bash
npm install
npm run dev
```

Stack: React 19, Vite, Bootstrap, Oxlint.

Een groter React-project van mij is de [Pokémon Team Manager](https://github.com/Mister030/pokemon-team-manager).
